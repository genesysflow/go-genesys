Calling the API

curl -H "Authorization: Bearer $TOKEN" {{config "app.url"}}/api/blog/posts

GET /api-tokens tokens.index

Repository
TokenRepository.ListFor(user) reads the caller's tokens; Create returns the plaintext once and stores its hash.auth/tokens.go
Response
The same POST /api-tokens answers a browser with a redirect and a script with 201 JSON, decided by what the request accepts.
Guard
The API authenticates with PersonalAccessTokenGuard instead of the session, so no cookie is involved and CSRF does not apply.
Abilities
RequireAbility("posts:write") sits on the routes that write.auth/tokens.go
CSRF
/api/ is exempt because a bearer token is not sent automatically by a browser.routes/routes.go
